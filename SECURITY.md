# Security policy

## Supported versions

Report vulnerabilities against current `main` or the latest release tags.
Older tags are not maintained. Name the commit or tag you reproduced the
problem on.

## Reporting

Report a vulnerability in private through GitHub Security Advisories. On this
repository, choose [Report a vulnerability](https://github.com/Tyler-R-Kendrick/ts-autocode/security/advisories/new).
Do not open a public issue for an unpatched security problem.

This project publishes no security email address. Do not send a report to an
address you found elsewhere.

If that form is not available, private reporting is off. Maintainers must
enable it in repository Settings, then Security. On current GitHub that
control is Advanced Security, then Private vulnerability reporting.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Maintainers aim to acknowledge a report within 3 business days
and coordinate disclosure after a fix is available.

## Scope

This project generates and executes code. Reports are in scope when they
concern training, source rewriting, or the command-line interface, including
how generated or rewritten code is executed and how traces and secrets are
handled.
