# antislop

Follow `AGENTS.md`. Apply these checks during the work:

- Implement requested behavior and working controls; do not leave placeholders.
- Use existing product direction and components. Verify relevant states, themes,
  keyboard access, and responsive layouts when changing an interface.
- Use precise language and substantiated claims. Remove decoration and copy that
  do not serve the user.
- Write self-documenting code. Complete deferred work and do not create comments,
  plans, design or architecture documents, or audit backlogs.
- Run the checks appropriate to the change and report evidence in the response.
